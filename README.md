# MeowShot

**MeowShot by kimi** — лёгкая персональная замена базовому захвату экрана в Windows 10.

Целевая система: Windows 10 22H2 x64 (сборка 19045 и новее). Приложение написано на C# и WPF, работает в системном трее и не требует прав администратора.

## Возможности

- глобальная горячая клавиша `Ctrl + Shift + S`;
- захват прямоугольной области, отдельного окна или монитора;
- поддержка нескольких мониторов и разных значений масштабирования;
- PNG без потерь и без уменьшения исходного разрешения;
- мгновенное копирование снимка в буфер обмена;
- кликабельное системное уведомление с действиями «Редактировать» и «Сохранить как…»;
- редактор: обрезка, перо, кисть, маркер, размытие, пикселизация, закраска, линия, стрелка, прямоугольник, эллипс, текст, нумерованные шаги, ластик, отмена и повтор;
- изменение размера и перемещение уже выделенной области, отображение её точных размеров;
- быстрая панель «Готово / Редактировать / Сохранить» после выделения области;
- необязательное автоматическое сохранение в выбранную папку;
- необязательная локальная история с настраиваемым лимитом;
- необязательный курсор на снимке;
- автозапуск только для текущего пользователя.

## Использование

1. Запустите `MeowShot.exe`. Значок приложения появится в трее.
2. Нажмите `Ctrl + Shift + S`.
3. Выберите режим на панели сверху и укажите область, окно или монитор.
4. При необходимости скорректируйте область за края или переместите её целиком.
5. Нажмите «Готово»: снимок окажется в буфере, а уведомление откроет редактор или диалог сохранения.

Поведение после снимка, уведомления и быструю панель можно независимо менять в настройках.

Правый щелчок по значку в трее открывает меню настроек, истории и выхода. Двойной щелчок начинает новый захват.

## Установка и portable-версия

GitHub Actions собирает два артефакта:

- `MeowShot-Setup-x64.exe` — установщик для текущего пользователя;
- `MeowShot-portable-x64.zip` — полностью автономная portable-сборка.

Установщик пока не подписан коммерческим сертификатом, поэтому Windows SmartScreen может показать стандартное предупреждение для нового издателя. Исходный код и workflow сборки доступны в этом репозитории.

Portable-версию следует распаковать в постоянную папку до включения автозапуска. Если затем переместить `MeowShot.exe`, откройте настройки и повторно сохраните их.

## Приватность

MeowShot не содержит аналитики и сетевых функций. Снимки никуда не отправляются. Настройки и включённая пользователем история находятся в `%LocalAppData%\MeowShot`. Автосохранение и история по умолчанию выключены.

## Ограничения текущей версии

- защищённое DRM-содержимое и некоторые аппаратные видеоповерхности могут получиться чёрными — это ограничение системного захвата;
- HDR преобразуется стандартными средствами рабочего стола; отдельное управление HDR-цветом запланировано на более позднюю версию;
- произвольная форма выделения пока не реализована;
- комбинация `Ctrl + Shift + S` фиксирована в первой версии.

## Что нового в 0.1.1

- новый логотип и значок MeowShot;
- рабочее системное уведомление, привязанное к конкретному снимку, и надёжная кликабельная карточка на случай недоступности Windows Notifications;
- размытие, пикселизация, широкая кисть, закраска и нумерованные шаги в редакторе;
- повторное изменение области захвата и быстрые действия;
- полностью обновлённое окно настроек и новые параметры поведения после снимка.

## Сборка

Понадобятся Windows 10/11 и .NET 10 SDK:

```powershell
dotnet restore MeowShot.sln
dotnet build MeowShot.sln -c Release
dotnet publish src/MeowShot/MeowShot.csproj -c Release -r win-x64 --self-contained true -o artifacts/publish
```

Готовую portable-версию и установщик можно получить скриптом:

```powershell
./scripts/build-release.ps1
```

Для компиляции установщика скрипт ожидает Inno Setup 6.

## Структура

- `src/MeowShot` — приложение;
- `src/MeowShot/Interop` — минимальный Win32 interop;
- `src/MeowShot/Services` — захват, буфер, настройки, хранение и трей;
- `src/MeowShot/Windows` — оверлей, редактор, настройки и история;
- `installer` — сценарий Inno Setup;
- `.github/workflows` — воспроизводимая Windows-сборка.
